Currently hosted at https://reforger.5fc.net/

This tool allows Arma Reforger server owners to quickly and easily rearrange their mod list to resolve loading-order errors. It also features the ability to update all mods to their most recent version with one click as well as to choose any previous version of any mod in the list.

100% clientside. Feel free to paste in just a modlist or even your entire server.conf. Features JSON error detection/correction and colorized brackets for easy nesting visualization.
