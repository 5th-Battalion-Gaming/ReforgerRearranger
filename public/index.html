    About this tool — Arma Reforger mod load order & Workshop version manager
    

      
What it does

      
A free, browser-based editor for Arma Reforger dedicated server configs. Paste your
      server config JSON (or just the mods array) and drag mods to change the
      load order, fetch each mod's complete version history from the Reforger Workshop, and
      pin or roll back any mod to any published version. The JSON stays in sync as you work,
      with line numbers, bracket-pair coloring, and precise error highlighting.

      
Frequently asked

      
How do I change the mod load order on my Reforger server? The load order is
      simply the order of the mods array in your server config. Drag rows here,
      then copy or download the updated JSON back to your server.

      
How do I roll a mod back to an older version? Set that mod's
      version field. This tool lists every published Workshop version of each
      mod so you can pick one from a dropdown instead of hunting through changelog pages.

      
Is my config uploaded anywhere? No — everything runs client-side. The only
      network traffic is read-only fetches of public Workshop changelog pages.

      
Why won't my config parse? Usually a trailing comma after the last item in a
      block. Trailing commas are tolerated here and flagged in red; any other JSON error is
      highlighted on its exact line, and Format rewrites the file as strictly valid JSON.
